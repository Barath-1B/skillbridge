## 📍 Key Locations

- **Frontend entry**: `client/src/main.jsx`
- **Backend entry**: `server/src/index.js`
- **Database config**: `server/src/config/db.js`
- **Seed data**: `server/src/seed/`
- **Component library**: `client/src/components/`
- **Backend modules**: `server/src/modules/*/`

## 📋 Project Info

- **Name**: SkillBridge
- **Type**: Full-stack MERN web application
- **Stack**: React 18 + Vite, Node/Express, MongoDB, Redux Toolkit, Tailwind CSS
- **Auth**: JWT (httpOnly cookies) + bcrypt

For project instructions and coding standards, see `CLAUDE.md`.
